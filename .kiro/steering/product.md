# Product constraints

PHANTOM is a browser workspace for lawfully obtained legacy programs. Preserve
Open legacy software → Inspect → Compatibility → Configure → Run. The original
guest application's actual viewport is the focus. No simulated program output.

DOS uses js-dos/emulators 8.5.3; two exact GPL DOS fixtures have local browser
observations. General DOS compatibility is experimental. Boxedwine is disabled;
no Windows application has been verified. ELF, PE64, Mac and disk boot execution
are unsupported. Format recognition never establishes executable compatibility.

Respect `AGENTS.md`. Work on one selected spec task, report changed files, exact
tests and blockers. No promotional filler or generated compatibility judgments.
Never attribute previous Codex work to Kiro. A screenshot proves only what it
actually captures; execution claims need input, output, cleanup and file-I/O tests.
